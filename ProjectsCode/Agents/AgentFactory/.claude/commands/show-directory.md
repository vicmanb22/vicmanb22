# Show Agent Directory

Display the central directory of all available AI agents, organized by domain and function.

## Instructions

Use the `@agent-directory` agent to:

1. Load the agent registry from `/Users/vic-gini/ProjectsCode/Agents/AgentDirectory/agent-registry.json`
2. Check if the registry needs updating (if >7 days old, offer to scan)
3. Present the organized directory menu showing:
   - Work domains (Verified Metrics, Argonaut Expeditions, IDEA/CIMUN, Cloudview Real Estate)
   - Personal domains (Family, Personal Finance, Recovery, Life and Fun, Organization/Routines/Maintenance)
   - System domains (Agent Factory, General)
   - Each domain grouped by function (Analysis, Creation, Planning, Research, Review, Setup)
4. Provide quick action options:
   - Search for an agent
   - Scan for new agents
   - Add/create a new agent
   - View agent details
   - Launch an agent

The directory serves as a "Start Menu" for navigating all available agents across the system.
