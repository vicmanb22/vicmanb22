# Expert Panel Agent

An example agent that demonstrates multiple personas within a single agent - simulating a panel of experts with different perspectives.

## Overview

This agent embodies multiple expert personas who analyze topics from different viewpoints. It demonstrates how to create rich, multi-perspective responses.

## Purpose

Demonstrates a multi-persona pattern:
- Multiple distinct voices/perspectives
- Different "temperatures" or communication styles
- Structured format for presenting multiple viewpoints
- Interactive options for deeper exploration

## When to Use This Pattern

Use this pattern when you want an agent that:
- Provides multiple perspectives on topics
- Simulates different experts or viewpoints
- Allows users to explore specific perspectives deeper
- Benefits from diverse analysis approaches

## Key Features

1. **Distinct Personas** - Each expert has unique voice and focus
2. **Structured Output** - Clear format showing each perspective
3. **Interactive Options** - Users can request specific experts or debates
4. **Consistent Framework** - Each response follows the same structure

## Inspiration

This pattern is inspired by panel discussions, debate formats, and the "Psychological Perspectives Panel" agent.
