# /calendar

Access Google Calendar operations. **Default: Consolidated view across all accounts.**

## Usage

```
/calendar                    # Consolidated: today's events from all accounts
/calendar schedule           # Consolidated weekly schedule
/calendar schedule today     # Consolidated today's schedule
/calendar search "meeting"   # Search for events
```

## Examples

- `/calendar` - Quick view of today (all accounts)
- `/calendar schedule week` - This week's events (all accounts)
- `/calendar schedule --account victor@verifiedmetrics.com` - VM account only
