# Landing Page Best Practices

Landing pages are focused conversion machines. Unlike homepages, they have one goal and one audience.

## Landing Page vs. Homepage

| Homepage | Landing Page |
|----------|-------------|
| Multiple audiences | Single audience |
| Multiple goals | Single goal |
| Navigation included | Navigation minimized/removed |
| Brand overview | Specific offer |
| Exploratory | Conversion-focused |

## The Single Goal Principle

**Rule:** One page, one goal, one CTA.

- Every element should support the single conversion goal
- Remove navigation that leads away from conversion
- Eliminate competing CTAs
- Cut anything that doesn't directly contribute to the goal

## Landing Page Structure

### Standard High-Converting Structure

1. **Hero Section**
   - Headline (main promise)
   - Subheadline (expand/clarify)
   - Primary CTA
   - Hero image/video
   - Optional: Social proof teaser

2. **Social Proof Bar**
   - Client logos
   - Star ratings
   - Customer count

3. **Problem Section**
   - Agitate the pain
   - Show you understand
   - Create urgency for solution

4. **Solution Section**
   - How your product/service helps
   - Unique mechanism
   - Key benefits (3-5)

5. **Features/Benefits Section**
   - Detailed value props
   - Feature → Benefit format
   - Supporting visuals

6. **Social Proof Section**
   - Testimonials
   - Case study excerpts
   - Results/stats

7. **How It Works** (if needed)
   - Simple 3-step process
   - Reduces complexity fear

8. **Objection Handling / FAQ**
   - Address top concerns
   - Build trust

9. **Final CTA Section**
   - Restate main benefit
   - Urgency/scarcity (if real)
   - Clear CTA
   - Risk reducer (guarantee, etc.)

## Hero Section Deep Dive

### Headline

**Must answer:** "What is this, and what's in it for me?"

**Approaches:**
- Benefit-first: "[Get Result] without [Pain]"
- Problem-first: "Stop [Problem] and Start [Positive]"
- How-to: "How to [Achieve Goal] in [Timeframe]"

### Subheadline

**Role:** Expand on headline, add specificity, qualify audience.

**Formula:** "[How it works] for [who it's for] so they can [benefit]"

### Hero Image/Video

- Show the product in use
- Show the transformation (before/after)
- Show happy customers
- Keep it relevant—no stock photos of random people

### Above-the-Fold Checklist

- [ ] Clear headline
- [ ] Supporting subheadline
- [ ] Primary CTA visible
- [ ] Some form of social proof
- [ ] Relevant visual

## Copy Best Practices

### Length

**Long copy vs. short copy:**
- More expensive = longer copy needed
- More complex = longer copy needed
- Colder traffic = longer copy needed
- More aware audience = shorter copy okay

**Key:** Long copy works if it's scannable and engaging. Boring copy fails at any length.

### Scannability

- Use headers to break up sections
- Bullet points for benefits
- Bold key phrases
- Short paragraphs (2-3 sentences max)
- White space between elements

### Voice & Tone

- Match your audience's language
- Use "you" more than "we"
- Be specific, not generic
- Avoid jargon (unless audience expects it)

### Benefit > Feature

| Feature | Benefit |
|---------|---------|
| AI-powered analytics | Know exactly which content will rank |
| 24/7 support | Get help whenever you need it |
| 256-bit encryption | Your data is safe and secure |

**Formula:** [Feature] so you can [Benefit]

## Form Optimization

### Form Length

**Rule:** Ask only for what you need.

- Each field reduces conversions
- Multi-step forms outperform long single-step forms
- Save "threatening" questions for last steps (phone, budget)

### Form Best Practices

- Start with easy questions (email, first name)
- Use inline validation
- Clear error messages
- Progress indicators for multi-step
- Mobile-optimized input fields

### Lead Magnet Forms

- Name + Email is often enough
- Consider email-only for cold traffic
- Add fields as lead value increases

## CTA Placement

- After hero section (above fold)
- After key benefits
- After testimonials
- At page end (final push)

**Sticky CTA:** Consider a sticky header/footer CTA for long pages.

## Technical Requirements

### Page Speed

- Load time under 3 seconds
- 40% abandon sites that take longer
- Conversion rate is 3x higher at 1 second

**Optimization:**
- Compress images
- Minimize scripts
- Use CDN
- Enable caching

### Mobile Optimization

- 50%+ traffic is mobile
- Full-width CTA buttons
- Tap-friendly elements (44px minimum)
- Test on actual devices

### Browser/Device Testing

- Test all major browsers
- Test iOS and Android
- Test tablet views
- Test slow connections

## A/B Testing Priorities

### Highest Impact Tests

1. **Headline** - Biggest impact element
2. **CTA copy** - Direct conversion impact
3. **Hero image** - First impression
4. **Social proof placement** - Trust building
5. **Form length** - Friction reduction

### Testing Guidelines

- Test one element at a time
- Run until statistically significant
- Test big changes before small tweaks
- Document and learn from every test

## Landing Page Types

### Lead Generation

- Goal: Capture email/contact info
- Offer: Lead magnet (guide, tool, assessment)
- Form: Short (name + email)
- CTA: "Get Free [Thing]"

### Click-Through

- Goal: Warm up for next page (pricing, checkout)
- Copy: Education-focused
- CTA: "See Pricing" / "Start Trial"

### Sales Page (Long-Form)

- Goal: Direct purchase
- Copy: Comprehensive, objection-handling
- Includes: Guarantee, urgency, full proof stack

### Webinar/Event Registration

- Goal: Get registrations
- Copy: Event value + speaker credibility
- Urgency: Date/time, limited spots

### Product Launch

- Goal: Build waitlist or early sales
- Copy: Novelty, exclusivity, urgency
- Social proof: Beta user testimonials

## Common Mistakes

1. **Too many CTAs/goals** - Dilutes focus
2. **Navigation present** - Escape routes
3. **Slow load time** - Abandonment
4. **Mobile neglected** - Lost conversions
5. **No social proof** - No trust
6. **Generic copy** - No differentiation
7. **Form too long** - Friction
8. **No clear value prop** - Confusion
9. **Weak headline** - No hook
10. **Missing urgency** - No reason to act now

## Landing Page Checklist

### Before Launch

- [ ] Single, clear goal
- [ ] Headline passes the 5-second test
- [ ] CTA is specific and benefit-driven
- [ ] Social proof is present and credible
- [ ] Form is as short as possible
- [ ] Page loads in under 3 seconds
- [ ] Mobile experience is solid
- [ ] No broken links or elements
- [ ] Thank you page is set up
- [ ] Tracking is configured

### Copy Check

- [ ] Benefits emphasized over features
- [ ] Voice matches target audience
- [ ] Objections addressed
- [ ] Scannable formatting
- [ ] No typos or grammar errors
