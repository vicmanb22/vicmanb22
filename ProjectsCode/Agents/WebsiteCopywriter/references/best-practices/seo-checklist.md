# SEO Checklist for Website Copy

Comprehensive SEO considerations for every page. Reference this during copy creation and final review.

---

## On-Page SEO Fundamentals

### Title Tag
- [ ] **Length:** 50-60 characters (will truncate in SERPs after ~60)
- [ ] **Primary keyword:** Include near the beginning
- [ ] **Brand name:** Include at end if space allows (| Brand Name)
- [ ] **Unique:** Every page has a distinct title
- [ ] **Compelling:** Would you click this in search results?

**Formula:** `[Primary Keyword] - [Secondary Benefit] | [Brand]`

**Examples:**
- `Project Management Software for Remote Teams | Acme`
- `How to Run Effective 1:1 Meetings (Template Included) | Acme`

### Meta Description
- [ ] **Length:** 150-160 characters
- [ ] **Primary keyword:** Include naturally
- [ ] **Call to action:** End with action verb
- [ ] **Unique:** Every page has a distinct description
- [ ] **Compelling:** Sell the click

**Formula:** `[What the page offers]. [Key benefit]. [CTA].`

**Example:**
`The project management tool built for remote teams. Async-first communication, timezone-aware scheduling. Start your free trial today.`

### URL Structure
- [ ] **Short and descriptive:** `/project-management-software/` not `/page?id=123`
- [ ] **Includes keyword:** When natural
- [ ] **Lowercase:** All lowercase, hyphens between words
- [ ] **No special characters:** Avoid underscores, spaces, symbols
- [ ] **Hierarchy reflects site structure:** `/blog/category/post-title/`

## Header Hierarchy

### H1 (Page Title)
- [ ] **One per page:** Exactly one H1
- [ ] **Includes primary keyword:** Naturally, not forced
- [ ] **Compelling:** Works as both SEO target and user headline
- [ ] **Unique:** No duplicate H1s across site

### H2s (Section Headers)
- [ ] **Logical structure:** Break page into scannable sections
- [ ] **Include variations:** Related keywords, long-tail phrases
- [ ] **Match search intent:** Question-based H2s match voice search
- [ ] **Hierarchy respected:** H2s under H1, H3s under H2s

### H3s and Below
- [ ] **Subsection organization:** Further break down H2 sections
- [ ] **Long-tail opportunities:** Target specific questions
- [ ] **Don't skip levels:** Never go H1 → H3 (skip H2)

**Example Structure:**
```
H1: Project Management Software for Remote Teams
  H2: Why Remote Teams Need Specialized Tools
    H3: The Challenge of Async Communication
    H3: Managing Across Time Zones
  H2: Key Features for Remote Work
    H3: Async-First Communication
    H3: Timezone-Aware Scheduling
  H2: How [Product] Helps Remote Teams
```

## Keyword Integration

### Primary Keyword Placement
- [ ] Title tag
- [ ] H1 headline
- [ ] First paragraph of body copy
- [ ] At least one H2
- [ ] Image alt text (hero image)
- [ ] URL (if possible)
- [ ] Meta description

### Secondary Keyword Usage
- [ ] Spread throughout H2s and H3s
- [ ] Use variations and synonyms
- [ ] Include in body copy naturally
- [ ] Use in image alt text where relevant

### Keyword Density
- **Avoid:** Keyword stuffing (reads unnaturally)
- **Aim for:** 1-2% density for primary keyword
- **Focus on:** Natural language, semantic variations
- **Use:** Related terms, LSI keywords

### Long-Tail Opportunities
- [ ] Target questions in FAQ sections
- [ ] Use "how to," "what is," "best" phrases
- [ ] Create specific use case or persona content
- [ ] Address problems in user language (VOC)

## Content Quality Signals

### E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness)

**Experience:**
- [ ] First-hand knowledge demonstrated
- [ ] Real examples from actual use
- [ ] Specific details that show familiarity

**Expertise:**
- [ ] Author credentials visible
- [ ] Accurate, well-researched content
- [ ] Technical depth appropriate to audience

**Authoritativeness:**
- [ ] Links to authoritative sources
- [ ] Cited by others (over time)
- [ ] Consistent with industry consensus

**Trustworthiness:**
- [ ] Clear author attribution
- [ ] Contact information visible
- [ ] Privacy policy and terms linked
- [ ] HTTPS (site-wide)
- [ ] Updated/reviewed dates shown

### Content Completeness
- [ ] Answers the user's query comprehensively
- [ ] Addresses follow-up questions
- [ ] Longer than competing content (when depth adds value)
- [ ] Includes unique information (information gain)

## Internal Linking

### Best Practices
- [ ] **Link to relevant pages:** Connect related content
- [ ] **Use descriptive anchor text:** Not "click here," but "[keyword-rich phrase]"
- [ ] **Link from high-authority pages:** Homepage links carry most weight
- [ ] **Create content hubs:** Pillar pages linked to cluster content
- [ ] **Update old content:** Add links to new relevant pages

### Link Placement
- [ ] Within body content (most valuable)
- [ ] In "Related Content" sections
- [ ] Navigation (site-wide)
- [ ] Footer (lower value but useful)

### Anchor Text Guidelines
- **Good:** "Learn more about [project management for remote teams]"
- **Bad:** "[Click here] to learn more"
- **Avoid:** Over-optimized exact-match anchors (looks spammy)

## Image SEO

### File Naming
- [ ] **Descriptive names:** `remote-team-project-management.jpg` not `IMG_12345.jpg`
- [ ] **Include keywords:** Where natural
- [ ] **Use hyphens:** Between words

### Alt Text
- [ ] **Describe the image:** What is shown
- [ ] **Include keyword:** When relevant and natural
- [ ] **Keep concise:** 125 characters or less
- [ ] **Don't keyword stuff:** Describe, don't optimize

**Example:** `Remote team members collaborating on project timeline in Acme software`

### Technical Optimization
- [ ] **Compress images:** WebP preferred, <200KB for hero images
- [ ] **Responsive images:** Serve appropriate sizes for devices
- [ ] **Lazy loading:** For below-the-fold images
- [ ] **Specify dimensions:** Prevent layout shift

## Technical SEO Considerations

### Page Speed Impact on Copy

**Fast Loading Priorities:**
- Keep above-the-fold content lightweight
- Lazy load images below the fold
- Minimize custom fonts (or preload)
- Avoid render-blocking scripts

**Copy Implications:**
- Hero section should render with minimal resources
- Consider text-based social proof (loads faster than logo images)
- Testimonial photos can lazy load

### Mobile-First
- [ ] Copy works at 320px width
- [ ] Headlines don't awkwardly break
- [ ] CTAs are thumb-reachable
- [ ] Forms are easy to complete on mobile
- [ ] Font sizes are readable (16px minimum)

### Schema Markup Recommendations

| Content Type | Schema |
|--------------|--------|
| FAQ section | FAQPage |
| How-to content | HowTo |
| Product pages | Product |
| Reviews/testimonials | Review, AggregateRating |
| Articles/blog | Article |
| Organization info | Organization |
| Pricing | Offer |

## AEO (Answer Engine Optimization)

For visibility in AI-generated answers (ChatGPT, Claude, Perplexity):

### Content Structure
- [ ] Lead with direct answers (don't bury the lead)
- [ ] Use clear, extractable statements
- [ ] Structure with tables for comparisons
- [ ] Include TL;DR summaries
- [ ] Use descriptive headers that match question phrasing

### Information Gain
- [ ] Say something others don't say
- [ ] Include original data, research, or frameworks
- [ ] Provide specific numbers and examples
- [ ] Avoid generic, "typical" content

### Comprehensiveness
- [ ] Answer every follow-up question
- [ ] Think in topic clusters, not single keywords
- [ ] Cover the full range of queries on a topic

### Citations and Mentions
- [ ] Get mentioned on Reddit, YouTube, industry sites
- [ ] Aim for multiple citations across sources
- [ ] Help center content answers specific questions

## Competitor Keyword Analysis

### What to Research
- [ ] **Ranking keywords:** What terms do competitors rank for?
- [ ] **Content gaps:** What topics do they not cover well?
- [ ] **Featured snippets:** Which queries show snippets you could win?
- [ ] **Question keywords:** What questions do people ask?

### Opportunity Identification
- **Low-hanging fruit:** High volume, low difficulty keywords competitors rank for
- **Gaps:** Topics competitors don't address
- **Better content:** Topics where you can create more comprehensive content
- **Long-tail:** Specific queries no one owns

## Pre-Publish SEO Checklist

### Before Going Live
- [ ] Title tag optimized
- [ ] Meta description written
- [ ] URL structure finalized
- [ ] H1 includes primary keyword
- [ ] Header hierarchy is logical (H1 → H2 → H3)
- [ ] Keywords integrated naturally
- [ ] Images optimized (file names, alt text, compression)
- [ ] Internal links added
- [ ] External links to authoritative sources (where helpful)
- [ ] Schema markup added (if applicable)
- [ ] Mobile preview checked
- [ ] Page speed tested

### After Publishing
- [ ] Submit to Google Search Console
- [ ] Check indexation status after 1-2 days
- [ ] Monitor rankings for target keywords
- [ ] Track organic traffic to page
- [ ] Update content as needed based on performance

## Common SEO Mistakes in Copy

### Avoid
1. **Keyword stuffing:** Unnatural repetition
2. **Thin content:** Not comprehensive enough to rank
3. **Duplicate content:** Same copy across multiple pages
4. **Missing H1:** Or multiple H1s
5. **Skipping alt text:** On important images
6. **Generic meta descriptions:** Or missing entirely
7. **Ignoring mobile:** Copy that only works on desktop
8. **No internal links:** Orphan pages with no connections
9. **Outdated content:** "Best tools for 2023" in 2025
10. **Over-optimization:** Obvious SEO writing that hurts UX
