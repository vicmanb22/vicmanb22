# Expert Interviews & Podcast Synopses

This folder contains synopses of expert interviews, podcasts, and talks related to website copywriting and conversion optimization.

## How to Add New Interview Notes

Create a new markdown file with this structure:

```markdown
# [Expert Name] - [Topic]

**Source:** [Podcast name, interview link, or event]
**Date:** [When recorded/published]
**Expert Credentials:** [Brief background]

## Key Insights

- [Insight 1]
- [Insight 2]
- [Insight 3]

## Actionable Takeaways

1. [Specific action you can take]
2. [Another specific action]

## Notable Quotes

> "[Memorable quote]"

## Related Topics
- [Link to related reference files]
```

## Naming Convention

Use: `[expert-lastname]-[topic-slug].md`

Examples:
- `schwartz-market-awareness.md`
- `cialdini-persuasion-update.md`
- `hormozi-offer-creation.md`

## Suggested Sources

- **Podcasts:** Everyone Hates Marketers, Copyblogger FM, The Copywriter Club
- **YouTube:** Conversion experts, marketing channels
- **Conferences:** MicroConf, CXL Live, Conversion Conference
- **Books:** Summarize key chapters from copywriting books
