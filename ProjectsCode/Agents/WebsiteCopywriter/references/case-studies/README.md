# Case Studies - High-Converting Website Examples

This folder contains analyses of websites with proven high conversion rates, documenting what makes them effective.

## How to Add a Case Study

Create a new markdown file with this structure:

```markdown
# [Company/Site Name] - [Industry]

**URL:** [website URL]
**Type:** [Landing page, SaaS homepage, E-commerce, etc.]
**Analyzed:** [Date]

## Overview

[Brief description of the company and what they sell]

## What They Do Well

### Hero Section
- [Specific technique and why it works]

### Social Proof
- [How they use testimonials, logos, stats]

### Copy Techniques
- [Notable copywriting patterns]

### Design/UX Elements
- [How design supports conversion]

## Specific Techniques Used

| Section | Technique | Why It Works |
|---------|-----------|--------------|
| Hero | [technique] | [explanation] |
| CTA | [technique] | [explanation] |

## Results (if available)

- [Conversion rate]
- [A/B test results]
- [Growth metrics]

## Key Takeaways

1. [Actionable insight]
2. [Another insight]

## Screenshots

[Add screenshots to a subfolder if helpful]
```

## Naming Convention

Use: `[company-name]-[industry].md`

Examples:
- `stripe-fintech.md`
- `basecamp-saas.md`
- `glossier-ecommerce.md`

## Categories to Cover

- **SaaS:** B2B software landing pages
- **E-commerce:** Product pages, category pages
- **Lead Gen:** Service businesses, agencies
- **Personal Brand:** Course creators, consultants
- **Non-Profit:** Donation pages
