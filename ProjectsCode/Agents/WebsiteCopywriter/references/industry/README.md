# Industry-Specific Guidance

This folder contains copywriting guidance tailored to specific industries, including unique considerations, compliance requirements, and proven patterns.

## How to Add Industry Guidance

Create a new markdown file with this structure:

```markdown
# [Industry Name] Website Copy Guide

## Industry Overview

[Brief description of the industry and typical business models]

## Unique Considerations

- [What makes this industry different]
- [Buyer behavior patterns]
- [Decision-making factors]

## Regulatory & Compliance Notes

- [Required disclaimers]
- [Restricted claims]
- [Legal considerations]

## Common Objections & How to Address Them

| Objection | How to Address |
|-----------|----------------|
| [objection] | [copy approach] |

## Successful Patterns

### Headlines That Work
- [Pattern 1]
- [Pattern 2]

### Social Proof Approaches
- [What types work best]

### CTAs That Convert
- [Effective CTA patterns]

## Words/Phrases to Use

- [Industry-specific terminology that resonates]

## Words/Phrases to Avoid

- [Terms that don't work or cause issues]

## Example Sites

- [URL 1] - [Why it works]
- [URL 2] - [Why it works]
```

## Naming Convention

Use: `[industry-name].md`

Examples:
- `saas-b2b.md`
- `healthcare.md`
- `financial-services.md`
- `ecommerce-fashion.md`
- `real-estate.md`
- `legal-services.md`
