# Project References

Drop files into these folders to provide context for the Website Copywriter agent. The agent reads these materials during research to inform copy recommendations.

## Folder Structure

### brand/
Brand guidelines and style information:
- Brand style guides (PDF, DOC)
- Tone of voice documents
- Logo usage guidelines
- Color palettes
- Typography specs
- Terminology/glossary
- "Do's and Don'ts" for messaging

### content/
Existing content to reference or port over:
- Current website copy
- Blog posts
- Case studies
- Marketing collateral
- Email templates
- Sales decks
- Product documentation

### competitors/
Competitor intelligence:
- Competitor website URLs
- Screenshots of competitor pages
- Notes on what competitors do well/poorly
- Competitor messaging analysis
- Pricing comparisons

### seo/
SEO and analytics data:
- Keyword research spreadsheets
- Google Search Console exports
- Google Analytics data
- SEMRush/Ahrefs reports
- Backlink data
- Current ranking pages

## Tips

1. **File formats**: The agent can read .md, .txt, and most text-based files. For PDFs and images, provide a text summary.

2. **Be specific**: The more detailed your reference materials, the better the copy recommendations.

3. **Update anytime**: Add new materials between sessions. The agent checks for updates.

4. **Organize clearly**: Use descriptive filenames so the agent knows what each file contains.
