## 🤖**Template Prompt Example to Reuse in AI**

You can copy–paste the following prompt whenever you want the AI to generate new ones:

---

**Prompt:**

Context of our Business: I am creating a database of our product & services use cases as part of our company’s Product Handbook and External Use (e.g. Landing Page of our Website). Our own AI model that aids in faster financial analysis, through the use of LLM itself, cutting out menial tasks and utilize key information for multiple use cases all with added data security. We also have a team of professionals with extensive background in finance and accounting from big 4 accounting firms.

Generate a marketing-style use case document for the task **[insert task name]**, target audient for this task is **[insert personas]** at **[insert use cases]** stage, following this structure:

1. **Category Header (task name)** — Add a tagline that emphasizes the outcome (e.g., *‘Smarter forecasting, not manual guessing’*).
2. **Sub-use cases (2–3 per category)**:
    - Each should have a **short bold headline** that expresses the key benefit.
    - Follow with a **1–2 sentence description** that highlights:
        - Automation from direct data integration,
        - AI-assisted analysis and insights,
        - Security and trustworthiness (if relevant),
        - Professional finance expertise available (if relevant).

Keep the tone **consulting-grade, concise, and benefit-oriented**, similar to investor or CFO-facing collateral. Use the writing style from SaaS marketing for finance products (like FP&A tools).
